# 广义的"花"识别规则（flower_resemble）

> 版本 v1.0 · 2026-07-26 · 效力：本文件是「广义的花」链路的业务规则单一事实来源；
> 代码实现改动必须同步本文件与 `flower-resemble` skill。

## 1. 介绍

对于广义的"花"，支持用户对一段视频做视觉搜索：根据视频内物体的**形态、颜色、质感**，
对应检索到现实世界中最相似的一种花，转化为可种入双人花园的花朵。

典型内容：烟花、猫爪开花、喷泉、蒲公英式炸开瞬间、伞撑开等"形状/动态像花"的非花主体。

## 2. 输入与约束

- 输入：用户上传视频（mp4 / mov / webm，≤ 30MB）。抖音 feed 浮标为上游入口形态，
  本期以前端「视频识花」入口承载同一链路。
- 抽帧：**每 3 秒截取 1 帧**，最多 6 帧（覆盖 18 秒；超出部分忽略）；
  帧统一缩放到宽 384px、JPEG（帧数与尺寸是 VLM 延时主因，控制 payload 防前端超时）。
- 首帧同时作为识别记录的封面图（image_url），供结果页与记录详情展示。

## 3. 实现流程（两段式）

### 3.1 第一段：VLM 主体属性抽取（seed 多模态模型）

输入：抽出的全部帧（detail=low，与拍照识别同策略）。
任务：识别视频主体并抽取固定属性字段，只输出 JSON：

```json
{
  "subject": "主体名（简洁中文名词，如 烟花 / 猫爪 / 喷泉）",
  "shape": "形态（整体轮廓与结构，如 放射状球形炸开 / 五瓣扇形展开）",
  "color": "颜色（主色调，简洁中文，如 金红 / 粉白）",
  "texture": "质感（如 丝绒 / 绒毛 / 水雾 / 玻璃质感）"
}
```

字段校验：四字段均必须非空，缺一即视为本次识别失败（降级 mock，不中断体验）。

### 3.2 第二段：属性 → 花卉检索匹配（seed 文本模型）

输入：第一段 JSON 属性（作为关键词）。
任务：以形态为主、颜色与质感为辅，检索现实世界中**最相似的一种真实花卉**，
输出与「拍照识别」完全一致的格式：

```json
{
  "species": "中文通用品种名",
  "main_color": "红/粉/白/黄/紫/蓝/橙/绿 之一",
  "secondary_color": "同上，单色花与主色相同",
  "form": "rosette/daisy/disk/cup/lily/ball/cluster 之一（花型枚举见 catalog.py）",
  "confidence": 0.0-1.0,
  "reason": "一句话说明为什么像（如：烟花放射状炸开的金色轨迹像蒲公英的绒球）"
}
```

校验与回落规则与拍照识别一致：species/main_color 非空；form 非法值经
`catalog.form_for()` 回落；confidence 截断到 0.85–0.97。

### 3.3 展示与后续流程

- 识图页 / AI 科普页：版式与「拍照识别」一致；额外展示「相似理由」区——
  视频主体四属性 + reason（数据来源：`RecognitionOut.resemble`，拍照识别该字段为 null，前端不渲染）。
- 之后流程与拍照识别完全一致：同一 Recognition 表、同「进入花园」种植、
  同一套线稿阶段图/特写图（species + main_color + form 驱动）、同一科普文案异步补齐。

## 4. 降级与容错

- 任一段 Ark 调用失败（网络/超时/JSON 校验不过）→ 第一段先用前 3 帧重试一次，
  再失败则整体降级 mock：按视频字节哈希确定性命中图鉴品种 + 模板化属性，保证 Demo 不中断（与拍照识别同策略）。
- 视频无法抽帧（损坏/格式不支持）→ 422「视频无法解析，换一个试试」。
- 抽帧工具：imageio-ffmpeg（pip 自带静态 ffmpeg 二进制，Render 免装系统依赖）。
- 延时预算：免费层冷启动（约 50s）+ 大视频上传 + 两段式调用可能超过 2 分钟，
  前端视频端点超时设为 280s，P1 分析页有分阶段提示文案。

## 5. 接口

`POST /api/v1/recognitions/video`（multipart，字段 `video`）→ 响应 schema 与
`POST /api/v1/recognitions` 相同，多出 `resemble` 字段（null | 属性对象）：

```json
{
  "resemble": {
    "subject": "...", "shape": "...", "color": "...", "texture": "...", "reason": "..."
  }
}
```

识别记录入库时 `resemble_attrs` JSON 列持久化（旧行 NULL，轮询端点照常返回）。

## 6. 验收清单

1. mock 模式离线测试：视频端点 200、resemble 四属性 + reason 齐全、可种入花园；
2. ark 模式真实视频（烟花/猫爪）→ 匹配花卉在语义上合理，form 驱动线稿轮廓正确；
3. 前端：视频入口 → P1 分析动画（视频预览）→ P2 科普页（相似理由区）→ 种入花园全链路；
4. 拍照识别链路回归不破（resemble=null，页面不渲染相似理由区）。

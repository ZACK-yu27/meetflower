# 花艺规则库（花束搭配 + 预览图生成）

> 本文档是业务规则的唯一事实来源；**代码实现为 `server/app/ai_gateway/floristry.py`（确定性执行）**。
> 规则由 Python 保证"每次都按规则执行"，LLM 只负责文案措辞（理由/搭配说明/包装建议），
> 长度校验不合格一律回落规则模板。改规则时本文档与 `floristry.py` 必须同步修改。
> 维护该链路前先调用 `floristry-rules` skill。

---

## 一、花束搭配

### 1. 推荐算法

1. 过滤 `quantity > 0` 的库存；按送花意图（occasion）给候选花材评分：
   - 品种命中意图偏好 **+3**；色系命中意图偏好 **+2**；提亮色（白/奶油等中性色）**+0.5**。
   - 意图偏好表见 `floristry.OCCASION_PREFS`。
2. 选择 **1 种主花**；有合适辅花（色彩协调、不与主花同品种同色）时再选 **1 种**。
   - 库存数量是"使用次数"而非朵数：花房的 1 个库存可支持使用若干朵鲜花。
   - 推荐基于用户自行选择的花材（若有）搭配。
   - 主/辅朵数约 **7:3**（配方固定：主 3 朵 / 辅 1 朵）；朵数是画面配方，**不与库存使用次数比较**；单种库存可做单花束。
3. 选择不与 items 重复、能提亮或增加层次的 `bonus_flower`；**默认优先满天星**（候选序：满天星·白 → 洋甘菊·白 → 满天星·紫）。赠送花材不占库存、`gifted: true`、`count = 1`。
4. 推荐理由 20–30 字（LLM 撰写，校验 10–45 字），写清主花、配花/赠送花材与送花意图；不合格回落规则模板。

### 2. 色彩规则

- **同色系优先；邻近色系次之**；互补色只保留一个高饱和主色。
- 白/奶油色最多约 **30%**，仅用于提亮。
- 花材主色最多 **2 种**，第 3 色只能是点缀或包装。
- 色系分组（`floristry.COLOR_FAMILY`）：红/粉/橙=暖红，黄=暖黄，蓝/紫=冷色，白=中性，绿=叶色。

### 3. 数量与排序

- 单种库存可做单花束；双种按主/辅约 7:3；三种以上在自由搭配中给精简建议。
- 推荐排序：库存可用 → 场景匹配 → 主辅清晰 → 色彩协调。

## 二、预览图生成

### 1. 编排配方

| 花材结构 | 构图 | 落位 |
| --- | --- | --- |
| 1 种 | 圆润半球形 | 同种花成簇，中心略高、边缘略低 |
| 主花 + 辅花 | 前低后高的圆三角 | 主花在中心偏前；辅花环绕两侧与前下方 |
| 主花 + 辅花 + 点缀 | 自然扇形三角 | 主花成组聚焦；辅花重复 2–3 处；点缀只填边缘空隙 |

- 赠送花材（gifted）按"点缀"处理，触发第 3 行配方。
- 主花必须最醒目，不能被绿叶、包装或点缀花遮挡；花头至少前后两层，避免齐平/机械并排。
- 主色集中在视觉中心；辅色在左右或前下方呼应。白/奶油仅提亮；高饱和色不超过 2 种。
- 绿叶只勾外轮廓、支撑层次；默认扇形双层包装 + 丝带，颜色取主色深浅色或低饱和中性色（`floristry.PACKAGING_COLORS`）。
- 画面必须可履约：`material_list` 全部花材及颜色可见；绿叶、包装等补充项在 packaging 文案中说明；不得出现清单外花种。

### 2. 生图提示词模板（`floristry.build_image_prompt`）

生成前先把花材转换为 `{{materials}}` = "x朵红玫瑰、x朵白满天星（赠送）"，并按上表生成 `{{structure}}` 和 `{{placement}}`；包装色由 `packaging_for(主花色)` 确定性查表。

```
一束写实鲜花花束的商业摄影，必须清楚呈现且只呈现这些花材：{{materials}}。
花艺结构：{{structure}}；花材落位：{{placement}}。主花集中在中心偏前，辅花向两侧与前下方展开，
花头前低后高、疏密自然，主色集中在视觉中心，辅色形成少量呼应。
包装：低饱和{{packaging_color}}双层扇形包装纸，{{ribbon_color}}丝带；暖米色纯色背景，柔和自然光，
浅景深，正方形构图，高级花艺摄影，花朵新鲜饱满。
禁止：文字、水印、人物、手绘风格、额外花种、错误花色、机械并排、遮挡主花、花材数量明显不符。
```

### 3. 文案要求

- `arrangement_note`：20–30 字（校验 10–40 字），说明主花、辅花/赠送花材和场景。
- `packaging`：10–20 字（校验 8–30 字），说明纸材、颜色、丝带及衬托关系，ark 模式附带规则库参考配色。
- 二者由同一 material_list + occasion 生成，不能与图片或清单矛盾；LLM 不合格一律回落 `floristry.note_template` / `floristry.packaging_template`。
